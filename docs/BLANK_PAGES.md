# 对页补页与补空白页

> issue #176。对页（双页对开）装订的书，每一章要从右页（奇数页）起。

## 用法

```latex
\pageSetup{对页补页=true}              % 章末在奇数页 → 自动补一页，下一章落在奇数页
\pageSetup{对页补页=true, 补页样式=空白} % 补出来的页完全空白

\补空白页                  % 在此处强制补一页（默认样式）
\补空白页[补页样式=空白]    % 强制补一页完全空白的页
```

| 中文 | 英文 | 说明 |
|------|------|------|
| `对页补页` | `facing-pages` | `\pageSetup` 键，默认 `false`。繁体 `對頁補頁` |
| `补页样式` | `blank-page-style` | `\pageSetup` 键与 `\补空白页` 的可选参数。`默认`／`header`（缺省）= 带版框、版心／页眉页码；`空白`／`blank` = 整页完全空白。繁体 `補頁樣式` |
| `\补空白页[...]` | `\InsertBlankPage[...]` | 强制补一页。繁体 `\補空白頁` |

写不认识的样式值会发出 `luatex-cn Warning`，并按默认样式处理。

## 规则

- **默认关闭**：不写 `对页补页` 时页数与以前完全一致。
- **奇偶按实体页序**：数的是已经输出的页，与页码显示（`\设置页码`、`\chapter` 重置页码）无关；多个 `正文` 块之间连续计数。
- **章末落在奇数页才补**：`\chapter`（`\卷`、`\chapter*`）出现在一页的最顶端、且这一页是偶数页时，在它前面补一页空白页。章在页中间起、或本来就落在奇数页，都不动。
- **只做奇数页起章**，不做偶数页起章。
- **筒子页模式**（`\开启分页`）下不自动补页——每张纸本身就是一对页；`\补空白页` 仍可用，补一整张。
- **强制补页永不被吞**：连写两次补两页；紧跟在 `\换页` 之后不会多补一页。
- 补页占的页码照常计入：补出来的页是前一章的最后一页，页码续排，下一章的页码重置不受影响。

## 补页样式

- **带页眉页码（默认）**：古籍类（`ltc-guji`）画版框与版心，版心里照常显示书名、章名、页码；竖排书类（`ltc-cn-vbook`／`ltc-tw-vbook`）照常带页眉与页码。
- **空白**：无版框、无版心、无页眉页码、无页码（未验证 `底色` 是否保留）。

## 在块内与块间

`\补空白页` 在 `正文` 内是一个排版指令（与 `\换页` 同级）；在两个 `正文` 之间则先收尾已打开的页，再单独排一页。两处写法一样。

## 实现要点

- 版面引擎新增 `PENALTY_BLANK_PAGE`（-10011）／`PENALTY_BLANK_PAGE_PLAIN`（-10012）；`pad_for_facing_pages` 在遇到章标记时判断奇偶（`luatex-cn-layout-grid.lua`）。
- 页的实体序号 = 已 shipout 的页数（`status.total_pages`）+ 1（上一块的末页仍开着时再 +1），由 `core.process` 传入布局阶段（`physical_page_base`）。
- 空白样式的页盒带 `ATTR_BLANK_PAGE` 属性，竖排书类的 shipout 钩子据此不画页眉页码。
- 不碰 `\pageSetup` 的边距与 `twoside` 逻辑：两个新键是 `.code:n` 处理器，直接写 Lua 状态。
