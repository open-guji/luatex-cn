# 扁字：用 `\填充文本框` 把长文压进固定格数（#79）

古籍里常见官衔、题名等长字串被压进固定格数的写法：字距不变、字形纵向压扁（扁字）。
`\填充文本框`（`\FillTextBox`）就是做这件事的：给定高度（格数或绝对长度），内容多于格数时
**整体纵向压缩**，字宽不变；内容不足时则均匀拉开。

## 用法

```latex
\填充文本框[17]{端明殿学士兼翰林侍读学士……赐紫金鱼袋}   % 旧写法：整数 = 格数
\填充文本框[height=17]{……}                              % 等价的键值写法
\填充文本框[height=120pt]{……}                            % 绝对高度
\填充文本框[height=4]{天地玄黄宇宙}洪荒                   % 6 字压进 4 格
```

- 方括号里只写整数时视为 `height=N`；要同时给别的键（`font-size`、`border` 等）请用键值写法。
- 无需额外宏包。`\填充文本框` 在 `ltc-guji` 的 `正文` 中直接可用，`列表`、`段落` 内同样可用。
- 压缩比 = 格数 ÷ 字数，字数越多越扁。83 字压进 17 格约压到 1/5，字形会接近横线，
  通常应同时减小字号（`font-size=`）、或增加格数，而不是硬压。
- 与 `\文本框` 的区别：`\文本框[height=N]` 不压缩，只是占 N 格并顶端对齐。

## 完整可编译示例

```latex
\documentclass{ltc-guji}
\title{明}
\chapter{序\\卷一}
\begin{document}
\begin{正文}
汉太史公司马迁

\begin{列表}
\item \填充文本框[height=17]{端明殿学士兼翰林侍读学士朝散大夫右谏议大夫充集贤殿修撰权判西京留司御史台上柱国河内郡开国侯食邑一千三百户食实封四百户赐紫金鱼袋}司马光
\item \填充文本框[3]{汉太史令司马迁}
\end{列表}
\end{正文}
\end{document}
```
