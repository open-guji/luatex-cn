# 夹注与正文字数不同（issue #82）

古籍常见正文每列 15 字、夹注每小列 20 字。夹注的字格高度可以独立于正文设置。

## 写法

```latex
\contentSetup{ n-char-per-col = 15 }   % 正文每列 15 字

正文……\夹注[font-size=22pt, n-char-per-col=20]{夹注内容……}正文……
```

- `n-char-per-col`（中文别名 `每列字数`）：夹注每小列字数。夹注格高 = 正文列高 ÷ N，
  所以夹注占满一整列时，每个小列恰好 N 字。
- `font-size`：夹注字号，需自己配，一般略小于格高。
- 想直接指定格高也可以用 `grid-height=22.5pt`；两者同时给出时以 `grid-height` 为准。

## 注意

- 这两个 key 是逐个 `\夹注[...]` 生效的，写在 `\夹注设置{...}` 里不会作为全局默认。
- 夹注前面还有正文时，该列的夹注小列只剩下余下的格数，不足 N 字，这是正常的。

可运行示例：`test/regression_test/basic/tex/jiazhu-chars.tex`。
