\Space[3]扁鵲陰陽脈法第二\\
脈，平旦曰太陽，日中曰陽明，晡時曰少陽，黃昏曰少陰，夜半曰太陰，雞鳴曰厥陰，是三陰三陽時也\\
少陽之脈，乍小乍大，乍長乍短，動搖六分。王十一月甲子夜半，正月、二月甲子王\\
太陽之脈，洪大以長，其來浮於筋上，動搖九分。三月、四月甲子王\\
\end{正文}
