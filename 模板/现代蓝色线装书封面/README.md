# 现代蓝色线装书封面

中华书局、广陵书社等出版的现代蓝色线装书封面版式（issue #170）。参照 CY/T 247—2021《线装书籍要求》。

| 短书名 | 长书名（边框自动增高） |
|:---:|:---:|
| ![短书名](preview-1.png) | ![长书名](preview-2.png) |

## 编译

```bash
cd 模板/现代蓝色线装书封面
lualatex 示例.tex        # 字体：TW-Kai（见 scripts/download_test_fonts.sh），或改用任意楷体
```

自己的文档：把 `现代蓝色线装书封面.cfg` 放在 tex 文件旁，`\documentclass[现代蓝色线装书封面]{ltc-guji}`。

## 用法

```latex
\documentclass[现代蓝色线装书封面]{ltc-guji}
\setmainfont{TW-Kai}
\无标点模式
\begin{document}
\begin{封面}[底色={38, 72, 120}]
  \蓝签书名{史記卷一}
  \蓝签小字[x=118mm, y=100mm]{漢　司馬遷　撰}
  \蓝签小字[x=100mm, y=200mm, font-size=18pt]{中華書局}
\end{封面}
\end{document}
```

### `\蓝签书名[键值]{书名}`

白底书名签：内框 + 外缘细线，**高度 = (字数 + 0.4) × 字号**，随书名长度自动增高。

| 键 | 默认 | 说明 |
|---|---|---|
| `x` | 128mm | 签右边缘距页面**右边**的距离 |
| `y` | 22mm | 签上边缘距页面上边的距离 |
| `font-size` | 30pt | 书名字号（字数按 `\tl_count:n` 计，书名里请勿夹命令） |

`\蓝签设置{x=..., y=..., font-size=...}` 可一次改默认值（如在导言区）。

### `\蓝签小字[键值]{文字}`

竖排小字（撰者、出版者等），位置可调。

| 键 | 默认 | 说明 |
|---|---|---|
| `x` / `y` | 100mm / 30mm | 同上，右边缘距页面右边／上边缘距页面上边 |
| `font-size` | 14pt | 字号 |
| `font-color` | `255, 255, 255` | 文字色（RGB 0–255） |
| `height` | 字数 | 列高（字数或长度） |

英文别名：`\BlueLabelTitle`、`\BlueLabelText`。

## 取值说明

- 页面：成品 185 mm × 260 mm（常见 16 开线装本）。cfg 中 `paper-width = 370mm` 是双页展开宽度，单页 185 mm。
- 封面色：藏青蓝 RGB(38, 72, 120)，经 `\begin{封面}[底色=...]` 传入，可自行改。
- 线装书装订在右侧，书名签置于封面左上（右边缘距页面右 128 mm）。

## 已知限制

- 悬浮文本框叠放次序不确定（引擎按哈希序绘制），所以书名签用**单个**悬浮盒实现；请勿让小字盒与书名签重叠。
- 书名签目前为白底 + 内框；未做红色边线等变体。
